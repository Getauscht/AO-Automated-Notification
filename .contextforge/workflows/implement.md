# Workflow: Implementação de Funcionalidades

## 1. Antes de Iniciar
- Obtenha o contexto procedural relevante chamando a ferramenta MCP `context_forge_get_context` com a descrição da tarefa.
- Caso o MCP não esteja configurado, leia `.contextforge/context/ACTIVE_CONTEXT.md`.

## 2. Durante a Implementação
- Respeite as regras de arquitetura e aprendizados consolidados retornados.
- Siga os contratos e convenções de estilo do projeto.

## 3. Após Concluir
- Se o usuário corrigir alguma abordagem ou regra de negócio durante o processo, avalie se a correção é reutilizável.
- Se for reutilizável, registre uma proposta via `context_forge_propose_learning`.
